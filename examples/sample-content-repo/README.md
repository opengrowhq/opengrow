# Sample content repo

This is what a target repo for OpenGrow's GitHub PR publishing looks like:
a plain Markdown blog under `content/posts/`, with frontmatter matching
what OpenGrow's Markdown export produces.

Use this as a testing target when trying out GitHub PR publishing locally —
point OpenGrow at a repo with this shape (or fork/copy this one) and confirm
a generated `ContentPiece` opens a PR that adds a new file under
`content/posts/` in the same format as `content/posts/example-post.md`.
