# Blog Formatting

## Overview

Formatting is part of the message. Google, AI Overviews, and readers all reward clear structure, short paragraphs, and scannable elements. Apply these rules during final review.

## When to Use

- Draft is complete and needs a final polish pass
- Post feels like a "wall of text"
- Open rate, scroll depth, or snippet capture is poor
- Converting a rough draft to a publishable Markdown file

## When NOT to Use

- Output is not a blog post (ads, emails, social posts have different rules)
- User only asked for an outline
- Draft is explicitly meant to be raw or stream-of-consciousness

## Quick Reference

| Element | Rule |
|---------|------|
| H1 | One per post, 30-65 chars, keyword-aware |
| H2 | Every 200-300 words of body content |
| H3 | Use when an H2 has 3+ distinct sub-points |
| Paragraph | 2-4 sentences, ≤60 words, topic sentence first |
| Opener | Primary keyword in first sentence; no "In today's world", "In this article", "Let's dive in" |
| Lists | Numbered for ordered steps; bullets for unordered items; items ≤25 words and parallel grammar |
| Snippet target | H2 as a question; first paragraph 40-55 words with direct answer |
| Bold | One key phrase per paragraph, not whole sentences |
| Links | Descriptive 2-4 word anchors; no "click here"; ≤1 outbound link per paragraph |
| Images | One per 300-500 words; WebP/AVIF; alt text 8-15 words; include width/height |
| Citations | Every number/percentage claim cites a source inline |
| End | Conclusion → CTA → author bio → updated date → related posts |

## Core Pattern

1. **Scan the structure.** Verify one H1, logical H2/H3 hierarchy, no skipped levels.
2. **Fix the first 100 words.** Lead with the primary keyword and a direct answer.
3. **Break up paragraphs.** Anything over 60 words or 4 sentences should split.
4. **Add scannable elements.** Convert sequences to lists, comparisons to tables, warnings to callouts (`> **Warning:** ...`).
5. **Check snippet targets.** Ensure one H2 is a direct question answered in 40-55 words.
6. **Audit links and citations.** Replace generic anchors; flag unverified claims with `[CITE: claim]`.
7. **Add end-of-post elements.** Conclusion, CTA, author bio, related internal links.

## Common Mistakes

- Long unbroken text blocks.
- Clever but unclear headings.
- Banned openers that waste the first 100 words.
- Bold entire sentences instead of one key phrase.
- Lists with inconsistent grammar or items over 25 words.
- Outbound link soup in one paragraph.
- Claims with numbers but no source.
